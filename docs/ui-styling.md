# Дизайн и UI (Верстка заданий)

## Строгая геометрия и Кибер-стиль
* Никаких скругленных углов (никаких `border-radius`, `rounded-md`, `rounded-lg`). 
* Используйте утилитарные классы сброса (например, `rounded-0` в Bootstrap).
* Интерфейс должен оставаться строгим, квадратным, в стиле технологичных панелей (хакерский/кибер-стиль). Цветовая гамма: темный фон (`bg-dark`, `bg-black`), контрастный текст (зеленый для Уровня 1, желтый/оранжевый для Уровня 2, красный для Уровня 3).

## Экономия токенов и Глобальные стили
* **ЗАПРЕЩЕНО писать теги `<style>` внутри `levelX.astro`**.
* В целях экономии токенов при генерации ИИ, используйте **ИСКЛЮЧИТЕЛЬНО** глобальные утилитарные классы платформы (Bootstrap / Tailwind). Не генерируйте собственные CSS-правила, если это не является жизненно необходимым для уникальной механики.

## Нулевая зависимость (Zero-Dependency)
* Сервер и все уроки должны быть абсолютно независимы от внешних интернет-ресурсов для работы в изолированной локальной сети.
* **Внешние ассеты (шрифты Google, внешние CDN) КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНЫ.**
* Все библиотеки (Bootstrap, React, Vue, Tailwind) должны быть скачаны и храниться локально в папке `public/static/`. Подключайте их через `<link rel="stylesheet" href="/static/...">` или `<script src="/static/..."></script>`.

## Базовый шаблон (TaskLayout)
Все страницы заданий (файлы `levelX.astro`) должны быть обернуты в глобальный компонент `TaskLayout.astro`. Это позволяет избежать дублирования базовой разметки HTML и решает проблемы с наследованием цветов.
* **Использование:** Импортируйте `<TaskLayout level={1|2|3}>` и поместите внутрь него HTML-код задания.
* Компонент сам подключит `bootstrap.min.css` и задаст нужные классы тегу `<body>` (`text-success`, `text-warning`, `text-danger` в зависимости от уровня, и темный фон).
* Также он подключает `task-global.css`, который содержит глобальные фиксы UI (например, фикс для Bootstrap `.card`, чтобы текст корректно наследовал цвет родителя `color: inherit`). Не дублируйте эти фиксы локально.
