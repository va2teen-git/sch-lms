# Геймдизайн: Уровень 3 (Аркада)

Третий уровень — это финальный "босс" урока. Он загружается в независимый `<iframe>`.
Из-за высокой сложности стейт-менеджмента (множество фаз, таймеры, счетчики), для создания Уровня 3 **обязательно использование React или Vue** (декларативный подход). Библиотека подключается локально из папки `/static/`.

## Требования к механике
1. **Длительность:** Задание должно состоять из **8-12 фаз (шагов)** или непрерывного потока усложняющихся задач.
2. **Динамика (Таймер):** Обязательное наличие убывающего таймера. Таймер может быть либо глобальным (на все прохождение), либо локальным (на принятие решения в конкретной фазе).
3. **Геймификация:** Задание должно иметь аркадный стиль (например: "отражение DDoS атаки", "взлом сервера на время", "дешифровка потока данных"). Приветствуются красивые анимации, шкалы здоровья, предупреждения о критическом уровне угрозы.
4. **Наказание за ошибки (Тотальный сброс):**
   В отличие от 1 и 2 уровней, на Уровне 3 **ЛЮБАЯ ошибка** (неверный клик, неверный ввод) или **истечение таймера** приводит к отправке сигнала `hardcore_reset` и **ПОЛНОМУ СБРОСУ** всего прогресса третьего уровня. Игрок отбрасывается на самую первую фазу (Шаг 1). Это создает высокое напряжение и соревновательный эффект.
