# API Телеметрии и Режим Хардкора

Платформа изолирует задания внутри `<iframe>`. Общение с платформой происходит исключительно через `window.parent.postMessage`.

## Стандарт Телеметрии
Все тренажеры обязаны отправлять телеметрию. Фиксируется начало работы, каждая попытка и завершение.

Формат сообщения:
```javascript
window.parent.postMessage({
    type: 'TELEMETRY_EVENT',
    mission_name: 'Урок 5 :: Архивация (Уровень 3)', // КРИТИЧНО: должно содержать префикс "Урок X"
    action_type: 'in_progress', // 'in_progress', 'level_complete', или 'hardcore_reset'
    status: 'in_progress', // 'in_progress' или 'completed'
    start_time: new Date(startTime).toISOString(),
    time_spent_sec: 45, // Секунд с начала уровня
    attempts_count: 2, // Количество попыток/ошибок
    success: false, // true только при успешном прохождении всего уровня
    action_log: [{time: "...", action: "click_btn"}] // Опционально, лог действий внутри фаз
}, '*');
```

> **Важно по `mission_name`:** Название миссии **обязательно** должно содержать префикс урока (например, `Урок 5`, `Урок 19`). Бэкенд (`/api/progress`) фильтрует все события в БД с помощью конструкции `WHERE mission_name LIKE '%Урок X%'` для подсчета открытых уровней. Если префикса не будет (особенно в событии `hardcore_reset` или `level_complete`), бэкенд не увидит это событие при загрузке страницы, что приведет к багам с открытием уровней (например, "вечно открытый 3-й уровень" после ошибки в хардкоре). Платформа (`[id].astro`) старается автоматически подставлять этот префикс, если он пропущен, но хорошей практикой является передача корректного названия напрямую из тренажера.

## Режим Хардкора (Глобальный)
В шапке SPA-интерфейса платформы есть переключатель "Режим Хардкора" (сохраняется между страницами). 
ИИ-агенту не нужно проверять состояние этого переключателя. Задача скрипта в задании — **при любой ошибке пользователя всегда отправлять сигнал сброса**:

```javascript
window.parent.postMessage({
    type: 'TELEMETRY_EVENT',
    action_type: 'hardcore_reset'
}, '*');
```
Если режим хардкора активен на уровне платформы, то этот сигнал вызовет полную перезагрузку **ВСЕХ заданий урока (всех iframe)**, стирая прогресс. Если не активен — платформа просто проигнорирует этот сигнал или запишет его в статистику ошибок.
