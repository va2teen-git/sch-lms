# ИНСТРУКЦИИ ДЛЯ ИИ (DISPATCHER)

Вы работаете над образовательной платформой School LMS (на базе Astro).
**В целях экономии контекста базовая документация разделена на модули.**

> ⚠️ **КРИТИЧЕСКОЕ ПРАВИЛО: ИЗОЛЯЦИЯ ПРОДАКШНА И РАБОТА ЧЕРЕЗ GIT WORKTREE**
> Боевой сервер запущен и непрерывно обслуживает учащихся из корневой директории `D:\school-lms` (порт 8080).
> **КАТЕГОРИЧЕСКИ ЗАПРЕЩАЕТСЯ** в каталоге `D:\school-lms`:
> 1. Переключать ветки Git (`git checkout`);
> 2. Запускать сборку (`npm run build`);
> 3. Запускать dev-сервер (`npm run dev`) или автотесты (`npm test`, Playwright).
> Любое из этих действий приведет к повреждению сборки `dist/`, падению боевого сервера или загрязнению боевой базы `telemetry.db`!
>
> **ПРАВИЛО РАЗРАБОТКИ:** Вся работа ИИ-агентов ведется **ИСКЛЮЧИТЕЛЬНО** в изолированном дереве `git worktree` по пути `D:\school-lms-dev`.
> По завершении задачи и создании PR агент **ОБЯЗАН** удалить временный worktree (`git worktree remove D:\school-lms-dev --force`).
> Подробный регламент: см. `docs/ai-workflow.md`.

КАТЕГОРИЧЕСКИ ЗАПРЕЩАЕТСЯ писать код по памяти или гадать. Перед выполнением любой задачи вы ОБЯЗАНЫ использовать инструмент чтения файлов, чтобы загрузить в контекст только нужную инструкцию из списка ниже:

1. **Геймдизайн (Уровни 1 и 2)** -> Читать `docs/design-levels-1-2.md`
   *(Zero Multiple Choice, Ур.1: манипуляции мышью, Ур.2: ручной ввод в поле, 3 и 5 фаз, генерация при ошибке)*
2. **Геймдизайн (Уровень 3 / Аркада)** -> Читать `docs/design-level-3.md`
   *(React/Vue, банк уникальных аркадных архетипов, таймеры, 8-12 фаз, полный сброс при ошибке)*
3. **Дизайн и верстка (UI)** -> Читать `docs/ui-styling.md`
   *(Кибер-стиль, локальный Bootstrap/Tailwind, запрет на `<style>` и CDN)*
4. **API Телеметрии, Модель Данных и Аналитика** -> Читать `docs/telemetry-api.md`
   *(Нормализованная схема SQLite: student_class, course_slug, lesson_id, level_number; формат postMessage, индексы, миграция, фильтрация учителя)*
5. **Учебный план и структура файлов** -> Читать `docs/curriculum.md`
   *(Связь с учебником Полякова, папка `wp/`, структура `src/`, запрет LaTeX и правила оформления формул в учебном виде)*
6. **Готовые компоненты (Терминал, Python IDE)** -> Читать `docs/components.md`
   *(Описание пропсов и использования `Terminal.astro` и `PythonIDE.astro`)*
7. **Рабочий процесс ИИ (AI Workflow & Worktree)** -> Читать `docs/ai-workflow.md`
   *(Изоляция боевого сервера, создание и очистка `git worktree`, гигиена веток, запрет висящих shell-процессов, регламент обновления продакшна и чек-лист качества)*
8. **Обязательное тестирование уроков** -> Читать `docs/testing.md`
   *(Требования к e2e тестам на Playwright, проверка телеметрии и хардкор-режима)*
